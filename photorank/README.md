# Photo Ranker

I have too many photos that I think are good. I need to make sure that I only show the top ones so that each one has more meaning.

I don't want to select the top 10 or so, but I don't mind comparing photos to each other, and letting it automatically show the top photos.

## About ELO Ratings

The ELO rating system (named after Arpad Elo) is a method for calculating relative skill levels. Originally designed for chess, it works perfectly for ranking photos too! All photos start at **1500 ELO**. When you pick a winner, both photos' ratings adjust based on the expected outcome. Upsets (lower-rated photo winning) cause bigger rating changes than expected wins. Switch between categories using the tabs to rank different photo collections!
